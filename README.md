
# Difference-Arrays-ArrayLists

## Project Description

This Java project demonstrates the differences between Arrays and ArrayLists using student names.

## Arrays in Java

An array stores multiple values of the same data type in a single variable. Its size is fixed when it is created. Individual elements can be updated, but the array cannot automatically grow or shrink.

## ArrayLists in Java

An ArrayList is a resizable collection that stores multiple elements. Unlike arrays, it can automatically grow or shrink as elements are added or removed. It provides built-in methods such as add(), remove(), get(), and size().

## Conceptual Differences

- Arrays have a fixed size.
- ArrayLists dynamically adjust their size.
- Arrays use the length property.
- ArrayLists use the size() method.
- Arrays can store primitive data types directly.
- ArrayLists use object types and support wrapper classes such as Integer.
- ArrayLists provide convenient methods for adding, removing, and accessing elements.

## Program Demonstration

The program creates an array and an ArrayList containing student names. It demonstrates how to update elements, display their contents, add new students, and remove existing students.
